# ADR 0001. Spring Boot 3.5.16 + Java 17 + Gradle 8.14

- 날짜: 2026-10-29
- 상태: 채택

## 배경

- 백엔드 PRD는 Java 17, Spring Boot 3.x로 정했다. 팀이 배운 멋사 14기 BE 강의 환경이 3.x 기준이다.
- 프로젝트를 만드는 시점(2026-10-29)에 Spring Initializr는 4.0.9 / 4.1.2만 제공한다.
- 3.x의 최신 패치는 3.5.16이고, 3.5의 OSS 지원은 2026-06-30에 끝났다(endoflife.date 기준).

## 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| 3.5.16 | 강의 코드·자료와 그대로 맞는다. 둘 다 익숙해서 해커톤 일정(약 2주) 안에 막힐 일이 적다 | OSS 지원이 끝나 보안 패치가 더는 나오지 않는다 |
| 4.1.2 | 현재 지원 중인 버전이다 | Jackson 3, 스타터 분리, 테스트 어노테이션 변경 등 바뀐 점이 많아 강의 코드와 다르다. 익히는 시간이 든다 |

## 결정

**Spring Boot 3.5.16**을 쓴다.

- 함께 쓰는 버전: Java 17(mise `temurin-17`), Gradle 8.14.6. Boot 3.5 Gradle 플러그인은 Gradle 7.6.4+ 또는 8.4+를 지원하고 9.x는 지원 범위에 없다.
- API 문서는 3.x 계열에 맞는 springdoc-openapi 2.8.x를 쓴다(추가 시점에 담당자가 버전을 확인한다).

## 결과

- 해커톤 기간에는 지원 종료가 문제되지 않는다고 판단했다. 대회가 끝난 뒤에도 서비스를 이어 간다면 4.x로 올리는 작업이 필요하다.
- 새 의존성은 Boot 3.5 의존성 관리(BOM)가 지정한 버전을 우선 쓴다.
